# Reports

Ce dossier contient les rapports générés automatiquement.

## Fichiers

### `csv_columns_report.csv` / `csv_columns_report.json`
Rapport d'analyse des colonnes disponibles dans les fichiers CSV du projet.

- **Format CSV** : Pour visualisation dans Excel/Google Sheets
- **Format JSON** : Pour intégration programmatique

## Génération
Ces rapports sont générés automatiquement lors de l'analyse des données du projet.
